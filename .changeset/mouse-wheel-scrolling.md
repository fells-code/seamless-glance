Scroll with the mouse wheel. The wheel behaves exactly like the up and down arrow keys: it moves the selection in list views and scrolls the help screen, describe and command overlays, and the profile picker when they are open. Mouse capture is released while a CLI command runs. Because the app now captures the mouse, selecting text in the terminal needs a modifier held while dragging (Shift in most Linux terminals, Option in iTerm2, Fn in macOS Terminal).
